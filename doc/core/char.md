# Declaring a char

In Java, the `char` data type is used to represent a single `16-bit Unicode` character. It can hold any character from the Unicode character set, which includes characters from many different languages and symbols.

## Characteristics of char

- `Size`: A char in Java is always 2 bytes (16 bits) because it is based on Unicode.
- `Single Quotes`: char literals are enclosed in single quotes (e.g., 'A', '1', '#').
- `Escape Sequences`: You can use escape sequences to represent special

characters:
`'\n'` for a new line
`'\t'` for a tab
`'\uXXXX'` for Unicode characters, where XXXX is the hexadecimal code.
